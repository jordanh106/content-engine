# Patient Comms

Workspace for Collective Family Chiropractic's patient and prospect communications: reactivation, reintroduction, nurture sequences, value resources, and call scripts.

## Goals

1. **Reactivate and reintroduce** the practice and services in a way that builds value for the reader before asking for anything.
2. **Engaging, non-generic sequences.** Specific, human, recognizably Jordan. No AI-slop copy.
3. **Leads on demand.** Stay front of mind so the booking schedule stays over-subscribed.

North star: deliver better than expected value, consistently, in places where most offices send nothing or send a generic "we miss you."

## Structure

| Folder | Contents |
|--------|----------|
| `research/` | Source analysis (video breakdowns, frameworks, swipe notes) |
| `sequences/` | Email/SMS sequences by segment (reactivation, new lead nurture, current patients) |
| `resources/` | Value assets (guides, checklists, lead magnets) the sequences point to |
| `call-scripts/` | Front desk and doctor scripts (reactivation calls, follow-ups, objection handling) |

## Rules

Inherits everything in `../brand.md`, plus:

- No emdashes.
- "You/your" language. Never clinical third-person.
- Every message must give something useful even if the reader never books.
- One clear ask per message.
- Read it out loud. If it sounds like any other chiropractor could have sent it, rewrite it.
