# Workflow: Content Calendar Planning

How to plan, batch, and schedule content production.

## The Batch-by-Category Method

Don't produce videos one at a time. Batch by audience segment or condition category.

**Session structure:**

| Phase | What You Do | Time |
|-------|-------------|------|
| Voiceover Night | Record all scripts for one category | 45-60 min |
| Generation Night | Generate all Cinema Studio shots for that category | 60-90 min (mostly waiting) |
| Assembly Night | Import to CapCut, sync audio, add captions, export | 60-90 min |

Three evenings = one entire category done.

## Recommended Production Order

Start with categories that have the most immediate impact:

1. **Highest emotional engagement** - Content that parents share, that new patients search for
2. **Strongest niche authority** - Content that positions you as THE expert in your specialty
3. **Broadest audience** - Content that reaches the most people
4. **Foundation content** - General education, new patient conversion
5. **Niche segments** - Smaller but loyal audiences

## Weekly Production Schedule

Aim for 2 production sessions per week (1.5-2 hours each).

| Week | Session 1 | Session 2 |
|------|-----------|-----------|
| 1 | Record Category A voiceovers | Generate Category A visuals |
| 2 | Assemble Category A | Record Category B voiceovers |
| 3 | Generate Category B visuals | Assemble Category B |
| 4 | Record Category C voiceovers | Generate Category C visuals |

## Content Mix Planning

Each week's published content should include:

- 2-3 AI-generated educational videos (from the content library)
- 2 real-footage videos (personality, office, patient interactions)
- Daily stories (behind the scenes, polls, Q&A)

## Using /last30days for Calendar Planning

Before each month, run:
```
/last30days [your industry] content trends --deep
```

Use the results to:
- Identify trending topics to prioritize
- Find content gaps no one else is covering
- Align with seasonal or current events
- Update the calendar with timely content hooks
