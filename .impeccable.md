## Design Context

### Users
**Primary user**: Jordan Harper, office manager and co-owner of Collective Family Chiropractic. Solo operator of the dashboard from desktop and iPhone. Uses this as a content production command center to plan, script, produce, and publish short-form video content across Instagram Reels, TikTok, YouTube Shorts, and YouTube long-form.

**Job to be done**: Move content ideas through a production pipeline efficiently during evening batch sessions (45-90 min). Track what's performing, discover trending formats, and maintain a consistent publishing cadence across 4 platforms.

**Context of use**: Evening sessions at home, often switching between desktop (deep work) and phone (quick capture, status checks). Needs instant orientation on what to do next and confidence that the system is working.

### Brand Personality
**Three words**: Warm, Editorial, Refined

**Voice**: The dashboard itself is a professional creative tool. It should feel like opening a beautifully designed notebook, not a corporate SaaS app. Quiet confidence. The brand behind the content (Collective Family Chiropractic) is nurturing and educational, but the dashboard is the creator's private workspace, so it leans more toward editorial craft than patient-facing warmth.

**Emotional goals**: Clarity (never overwhelmed), momentum (always know what's next), pride (this tool looks and feels premium).

### Aesthetic Direction
**Visual tone**: Warm editorial. Think Apple Music's content-forward layouts meets Stripe's polished data presentation. Generous whitespace, intentional typography hierarchy, subtle depth through layering rather than heavy shadows.

**Theme priority**: Light mode is the primary design target. Soft ivory and white surfaces, teal accents for interactive elements, warm coral for highlights. Dark mode is secondary but should feel equally considered (deep navy, bright teal glow).

**References**:
- **Apple Music / TV+**: Editorial layouts, generous imagery, smooth transitions, content-forward design, beautiful card treatments
- **Stripe Dashboard**: Polished data visualization, elegant charts, premium feel, clear information hierarchy, sophisticated use of whitespace

**Anti-references (explicitly avoid)**:
- Generic Bootstrap/Material UI template energy. No default shadows, no cookie-cutter cards.
- Overly playful or gamified aesthetics. No confetti, no cartoon icons, no excessive color. Keep it grown-up.
- Dense enterprise SaaS. No cramped data tables, no 12px-everything, no gray-on-gray corporate feel.

### Design Principles

1. **Editorial over industrial**: Every screen should feel like a curated page, not a data dump. Let content breathe. Use typography hierarchy and whitespace to create rhythm, not borders and dividers.

2. **Warmth through restraint**: The teal-and-ivory palette is warm by nature. Don't dilute it with too many competing colors. Let the accent palette (format colors, status colors) play supporting roles, never fighting for attention.

3. **Precision in the details**: Alignment, consistent spacing, intentional border radius, considered font weights. The difference between "good enough" and premium lives in 2px of padding and one font-weight step. Sweat the micro-decisions.

4. **Motion with purpose**: Animations should communicate state changes, not decorate. Use Emil Kowalski's principle: if an element moves, it should answer "what changed?" Spring-based easing for interactive elements, gentle fades for content loading. Never animate for spectacle.

5. **Content-forward hierarchy**: Thumbnails, video titles, and metrics are the primary content. UI chrome (navigation, filters, controls) should recede. The user's creative work should always be the visual hero, not the interface surrounding it.

### Tech Stack
- React 19, Vite 6, TailwindCSS 4 (integrated compilation, no separate config file)
- CSS custom properties for theming (light/dark via `:root` / `:root.dark`)
- Framer Motion 12 for complex animations
- lucide-react for iconography
- Recharts for data visualization
- cmdk for command palette
- clsx + tailwind-merge for class composition

### Component Conventions
- **Cards**: `bg-surface-elevated rounded-2xl border border-themed shadow-themed-sm`
- **Labels**: `text-[10px] font-black uppercase tracking-[0.2em] text-themed-muted`
- **Buttons**: `rounded-full text-[10px] font-black uppercase tracking-widest` (action) or `rounded-xl` (form)
- **Typography**: Georgia serif for headings, Nunito Sans for body. `font-serif font-bold` for display text.
- **Spacing**: `p-5` for card interiors, `gap-4` or `gap-6` between cards, `space-y-3` for stacked elements
- **Border radius**: `rounded-2xl` (cards/modals), `rounded-xl` (inputs/buttons), `rounded-full` (badges/pills)
- **Shadows**: Subtle only. `shadow-themed-sm` for resting, `shadow-themed-md` on hover elevation
- **Icons**: 16-18px from lucide-react. Stroke width 2. Muted color until interactive.
- **Format colors**: A=teal, B=emerald, C=sky, D=rose, E=violet, F=orange, G=pink (50/700 light, 500/20+400 dark)
